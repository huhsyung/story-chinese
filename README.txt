스토리 중국어 (데모)
- index.html 파일을 크롬 또는 엣지로 열면 바로 실행됩니다. 설치 필요 없음.
- 처음 마이크 버튼을 누를 때 '마이크 사용 허용'을 눌러 주세요. 음성 인식은 인터넷 연결이 필요합니다.
- 데모 범위: 1화 '도착', 2화 '룸메이트' (학습 목표 → 예습 → 말하기 실전 → 결말 → 피드백 → 복습 퀴즈 → 성취 확인)
- 말하기: 마이크를 누르고 10초 안에 말하기. 마지막 3초는 카운트다운 표시.
- 판정: 핵심 표현 포함 여부(2화 장면 3은 공손한 표현 + 동작 표현 여부). 향후 AI 판정으로 교체 예정.
- 기록은 브라우저(localStorage)에 저장됩니다.
